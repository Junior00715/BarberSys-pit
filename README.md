# BarberSys - Sistema de Agendamento para Barbearia

## 📌 Descrição da Solução
O **BarberSys** é uma aplicação web desenvolvida para otimizar o processo de agendamento de serviços em barbearias. A solução permite que os clientes consultem os serviços prestados, preços e durações, escolham horários disponíveis e realizem agendamentos online de forma rápida, facilitando também a gestão da agenda pelos barbeiros.

## 📐 Documentação
- **Diagramas UML:** Casos de Uso e Diagrama de Classes localizados na pasta `/docs/uml/`
- **Modelagem de Banco de Dados:** Scripts SQL e Dicionário de Dados localizados na pasta `/docs/banco-de-dados/`
- **Protótipo IHC:** Fluxo de telas e mensagens de feedback localizados na pasta `/docs/ihc/`

## 🛠️ Tecnologias Utilizadas
- **Linguagem Back-end:** Node.js (ou Python / PHP / Java)
- **Banco de Dados:** MySQL
- **Front-end:** HTML5, CSS3 e JavaScript
