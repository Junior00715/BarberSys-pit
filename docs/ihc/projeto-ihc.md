# 🖥️ Interface Humano-Computador (IHC) - BarberSys

## 1. Princípios de Interface Adotados
- **Clareza e Simplicidade:** Layout responsivo, focado na fácil navegação pelo celular ou computador.
- **Prevenção de Erros:** Campos de formulário com máscaras (telefone/data) e desabilitação de horários retroativos.
- **Feedback Constante:** Exibição de alertas visuais (mensagens de erro em vermelho e de sucesso em verde).

## 2. Principais Mensagens de Feedback ao Usuário
- **Sucesso (Verde):** *"Agendamento realizado com sucesso! Aguarde a confirmação."*
- **Erro de Validação (Vermelho):** *"O horário selecionado não está disponível. Por favor, escolha outro horário."*
- **Aviso (Amarelo):** *"Preencha todos os campos obrigatórios antes de prosseguir."*
